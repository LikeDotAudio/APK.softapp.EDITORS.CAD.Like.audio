## Findings
1. **Good: a versioned, origin-checked host bridge.** `HOST_PROTOCOL = 'cad.like.audio/host@1'` (`src/shell/hostBridge/hostBridge.ts`). Every post goes to `window.location.origin`, and incoming messages are dropped unless both `e.source` and `e.origin` match. The protocol is now published as `contract/host@1/` and held to it by `hostContract.test.ts`.
2. **Good: the vendored brand tokens have a drift gate.** `scripts/check-brand-tokens.mjs` fails a monorepo build when `src/tokens/brand.json` drifts from `contracts/tokens/brand.json`; `scripts/check-interfaces.mjs` now does the same for the Interfaces table.
3. **The smoke test checks the wrong page.** `Documentation/🧩Manual and Artifacts/SMOKE.md` gets HTTP 200 for the repo-root `index.html`, which loads `./src/main.tsx` and cannot run unbuilt. The launcher entry is `dist/index.html` (`display.json`). SMOKE.md is generated by the root `.apk.scripts/smoke.py`, which takes the first existing of `smoke.ini` `entries = index.html, dist/index.html`. **Waiting on root `.apk.scripts/smoke.py` (handoff filed)** to prefer `display.json` `entry`.
4. **Good: tests and gates run on every change.** `deploy.yml` runs `npm test`, then `npm run build`, which runs `tsc`, `verify` and `gates` (`package.json` `scripts.build`), before deploying.
5. **Big Picture's versioned path is client-side only so far.** The client asks `/api/v1/big-picture` first and falls back to `/api/big-picture` on 404; WEB.OsApi still serves only the legacy path and does not yet test against `contract/big-picture@1/`. **Waiting on WEB.OsApi (handoff filed).** The client side is delivered.
